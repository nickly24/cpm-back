Историческую миграцию 013 с очисткой данных не запускать. Подготовить повторяемый сценарий проверки/применения с проверкой схемы и сохранности данных.

8. Зафиксировать результаты тестов и миграции без секретов. Просмотреть diff, отдельно закоммитить изменения backend/frontend и выполнить обычный push в их текущие удалённые ветки. Не включать чужие изменения и не использовать force push.

## Согласованный контракт между частями реализации

- Источник: `section_kind=exam`; `section_ref_id` всего экзамена — его ID, части — `examId:partId`. Карточка: `card_ref=exam:examId:questionId`; progress section_ref_id всегда examId, чтобы перенос части не терял знание.
- Существующие student training API расширяются для exam; study response дополнительно содержит `exam`, `parts`, `part_id`; каждая часть совместима с TrainingSectionNode и имеет kind=exam, refId=examId:partId, part_id, part_code, статистику. Настройки возвращают last_part_id.
- Каталог узла exam: exam_id, parts_count, start_at, end_at; name содержит направление и номер экзамена. Экзамен с выключенным доступом не выдаётся студенту.
- Admin `GET/PATCH /api/exams/{id}/training` (PATCH: enabled, expectedVersion) возвращает exam с trainingEnabled; `GET /api/exams/{id}/training/preview` возвращает study response без записи прогресса и допускает скрытый/пустой банк для обладателя exams.view.
- `exams.training_enabled` boolean default false. В обоих student training таблицах section_kind расширяется до manual/test/exam, section_ref_id до VARCHAR(64). В настройках добавляется last_part_id BIGINT NULL. Остальные существующие данные не меняются.
- `last_batch_index=-1` обозначает всю выбранную область. `last_part_id=NULL` обозначает весь экзамен; `0` — удалённую последнюю часть, при которой «Продолжить» возвращает к выбору частей. Положительный ID указывает существующую выбранную часть. Этот маркер не сбрасывает настройки всего экзамена.
- Настройки области: last_batch_index=-1 означает все карточки выбранной области; 0 и больше — номер набора. last_part_id=null означает весь экзамен, положительный ID — последнюю часть, 0 — ранее выбранная часть удалена (открыть список частей). PUT настроек части также обновляет last_part_id корня, сохраняя его размер/режим/набор.
