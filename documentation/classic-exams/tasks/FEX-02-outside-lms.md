# FEX-02. Экзамен вне LMS

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-02-outside-lms.md).

## Цель

Сохранить старый формат экзамена и сделать его полноценным управляемым типом без рудимента «из 6».

## Функциональный результат

- Админ создаёт экзамен вне LMS для направления и календарной даты.
- Админ вручную добавляет, редактирует и удаляет результат студента.
- На студента в экзамене существует одна запись результата.
- Результаты массово загружаются через общий раздел «Загрузка» с preview.
- Старые записи продолжают отображаться.

## Модель результата

- студент;
- произвольные неотрицательные баллы;
- целая оценка 0–5;
- имя экзаменатора свободным текстом;
- экзамен и системные даты.

## Импорт

Файл содержит идентификатор/логин студента, баллы, оценку и экзаменатора. Preview обязан выявлять неизвестных студентов, дубли, отрицательные баллы и недопустимую оценку.

## Ограничения

- Не показывать максимум 6 и не валидировать баллы относительно 6.
- Апелляционный workflow к этому типу не применяется: админ редактирует результат напрямую.
- Удаление результата физическое.

## Зависимости

FEX-01.

## Критерии приёмки

- Ручной CRUD и импорт дают одинаковую модель результата.
- Студент видит дату, баллы, оценку и экзаменатора.
- Старые результаты читаются без потери данных.
- Рейтинг получает оценку 0–5, а не произвольные баллы.
