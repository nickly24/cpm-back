# FEX-05. Подсчёт, шкала и спорный результат

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-05-scoring.md).

## Цель

Создать единственный серверный движок расчёта взвешенных баллов, итоговой оценки и разрешения дробного результата.

## Функциональный результат

- Min всегда 0, max автоматически равен сумме `квота × вес`.
- Консенсус 0/0,5/1 умножается на целый вес части.
- Баллы рассчитываются точно через decimal arithmetic.
- Для оценок 0–5 используются строго возрастающие минимальные пороги.
- Дробный итог `.5` разрешается вверх, вниз или дополнительным вопросом.
- Дополнительный вопрос не добавляет баллы, а выбирает направление округления.

## Правила дополнительного вопроса

- Источник — конкретная часть либо случайная доступная часть.
- Консенсус 1 означает вверх, 0 — вниз.
- Для 0,5 применяется настройка: ещё вопрос, вверх или вниз.
- Режим «ещё вопрос» не имеет лимита.

## Ограничения

- Веса только целые положительные.
- Порог оценки 0 равен 0.
- Пороги 1–5 целые, строго возрастают и не превышают max.
- Frontend только визуализирует расчёт сервера.

## Зависимости

FEX-03; части из FEX-04 используются как вход, но движок должен тестироваться независимо.

## Критерии приёмки

- Для любого допустимого набора ответов результат воспроизводим.
- Ни один расчёт не зависит от binary float.
- Все ветви спорного результата дают согласованный целый итог.
- Изменение порогов немедленно меняет preview диапазонов.
