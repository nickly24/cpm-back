# FEX-03. Конфигурация классического экзамена

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-03-classic-config.md).

## Цель

Создать постепенно заполняемую конфигурацию классического экзамена без ручного статуса черновика.

## Функциональный результат

- После выбора направления экзамен существует сразу.
- Админ отдельно заполняет московский интервал и правила спорного результата.
- Неполный экзамен остаётся видимым.
- Готовность вычисляется отдельно и не является статусом экзамена.
- Начать новую сдачу можно только внутри интервала; завершить начатую можно после его окончания.

## Признаки конфигурации

- `direction_id` из FEX-01;
- `start_at` и `end_at` с семантикой Europe/Moscow;
- режим дробного итога: вверх, вниз или дополнительный вопрос;
- источник дополнительного вопроса: конкретная часть или любая;
- поведение при 0,5 за дополнительный вопрос: ещё вопрос, вверх или вниз.

## Ограничения

- Нет статусов draft/open/closed/archive.
- Нет таймера сдачи.
- Настройки можно редактировать после создания; организация обязуется не делать это во время проведения.
- При старте фиксируются правила и весь банк; редактирование/удаление исходной конфигурации не меняет начатую сдачу.

## Зависимости

FEX-01.

## Критерии приёмки

- Минимальная запись создаётся только с направлением и типом.
- Все настройки можно дозаполнить отдельными сохранениями.
- До/после периода новый старт запрещён, активная сдача доступна.
- Экзаменатор видит неполный экзамен и причину недоступности.
