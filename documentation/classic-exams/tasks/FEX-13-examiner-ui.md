# FEX-13. Кабинет экзаменатора

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-13-examiner-ui.md).

## Цель

Реализовать одинаково качественное mobile/desktop проведение экзамена комиссией без realtime-соединения.

## Функциональный результат

- Экзаменатор видит только свои экзамены и назначения.
- Неполный экзамен виден с причинами недоступности.
- Студенты имеют состояния: не начат, ожидание готовности, идёт, завершён.
- Экран готовности показывает полный состав.
- Экран вопроса показывает вопрос, эталон, три оценки, остаток замен и кнопку обновления.
- После своего голоса действия блокируются до нового раунда/консенсуса.
- Конфликт показывает раскрытый прошлый раунд и форму нового голосования.
- После консенсуса доступен следующий шаг.
- `stale_state` объясняется и предлагает обновиться.

## UX-ограничения

- Mobile-first responsive layout без потери функций.
- Нет автоматических сетевых обновлений.
- После каждой команды отображается возвращённое сервером состояние.
- Критические команды start/replace/next защищены от двойного нажатия.

## Зависимости

FEX-08, FEX-09, FEX-10, FEX-11.

## Критерии приёмки

- Полный сценарий работает на телефоне и desktop.
- Два браузера синхронизируются ручным обновлением.
- Экзаменатор не получает данные чужой комиссии.
- Обновление страницы не теряет прогресс или собственный голос.
