# FEX-04. Части и банк вопросов

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-04-question-bank.md).

## Цель

Дать админу управляемый банк простых текстовых вопросов, разделённый на устойчивые части A–Z.

## Функциональный результат

- В экзамене создаётся до 26 частей.
- Часть получает постоянный ID и уникальную редактируемую букву A–Z.
- Удаление части не переименовывает остальные.
- В части задаются целый положительный вес и целая положительная квота.
- Вопрос содержит простой текст вопроса и эталонного ответа в MySQL `TEXT`.
- Поддержаны ручной CRUD и Excel-импорт внутри карточки экзамена.

## Импорт

Колонки: `Часть`, `Вопрос`, `Эталонный ответ`. Новая допустимая буква создаёт часть без веса/квоты, после чего readiness указывает, что её нужно настроить. Preview блокирует пустые значения, неверные буквы и точные дубли.

## Ограничения

- Нет изображений, файлов, rich text и студенческого тренажёра.
- Вопрос принадлежит одному экзамену и не переиспользуется между экзаменами.
- При старте фиксируется immutable версия банка/частей; каждый показ ссылается на неё, не на текущий редактируемый банк.

## Зависимости

FEX-03.

## Критерии приёмки

- Ручной ввод и импорт формируют одинаковый банк.
- ID части не меняется после переименования буквы.
- Удаление B не меняет A/C.
- Длинный многострочный текст корректно сохраняется и показывается.
