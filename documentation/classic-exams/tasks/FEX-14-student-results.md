# FEX-14. Результаты экзаменов студента

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-14-student-results.md).

## Цель

Объединить результаты двух типов экзаменов в mobile-first представлении без участия студента в проведении.

## Функциональный результат

- В одном списке отображаются outside LMS и classic.
- Outside LMS показывает направление, дату, произвольные баллы, оценку и экзаменатора.
- Classic показывает период, расчётные баллы/max, оценку и состав комиссии.
- Полный протокол classic содержит показанные вопросы, эталоны, замены, дополнительные вопросы и консенсус.
- Персональные голоса и конфликтные раунды скрыты.
- После пересдачи текущим является второй протокол, первый доступен как история.
- После апелляции видна только текущая оценка с отметкой.

## Ограничения

- До появления результата карточка экзамена студенту не показывается.
- Результат публикуется немедленно после завершения.
- Банк вопросов отдельно не публикуется и не превращается в тренажёр.
- Студент может читать только собственные результаты.

## Зависимости

FEX-02, FEX-11.

## Критерии приёмки

- Представление корректно на мобильном экране.
- Старые outside LMS результаты не показывают «из 6».
- Пересдача и апелляция отражают действующее значение.
- API не раскрывает студенту персональные голоса комиссии.
