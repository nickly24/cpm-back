# FEX-15. Рейтинг и экзаменационная отчётность

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-15-rating-reporting.md).

## Цель

Интегрировать оба типа экзамена в существующий рейтинг и сводные отчёты без изменения общей формулы.

## Функциональный результат

- В экзаменационный компонент попадает итоговая оценка 0–5.
- Информационные баллы обоих типов напрямую не участвуют.
- Для classic используется пересдача, если завершена, иначе первая сдача; поверх неё — последняя апелляция.
- Каждый экзамен обязателен для каждого студента; отсутствие записи даёт 0 независимо от назначения.
- Outside LMS входит в период по дате.
- Classic входит в период по `start_at` и начинает учитываться со старта.
- Изменения/наступление start помечают рейтинг неактуальным; существующая кнопка запускает полный пересчёт с атомарной публикацией.
- Существующие отчёты получают одну строку/значение результата на exam+student.

## Ограничения

- Сохранить формулу homeworkAverage×0.25 + examAverage×6 + testsAverage×0.45. examAverage — среднее всех экзаменов, без дополнительного усреднения по направлениям.
- Переименование направления не создаёт новую рейтинговую сущность.
- Новые экспорты не создавать.

## Зависимости

FEX-02, FEX-11 и текущий модуль rating recalculation.

## Критерии приёмки

- Нет результата — ровно 0 в периоде.
- Пересдача и апелляция обновляют рейтинг идемпотентно.
- Удаление результата/экзамена удаляет его влияние.
- Существующие отчёты не дублируют первую и вторую попытки.
