# FEX-01. Единая модель экзамена и направления

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-01-exam-core.md).

## Цель

Создать общий экзаменационный агрегат для типов `outside_lms` и `classic`, связанный с единым направлением.

## Функциональный результат

- Экзамен создаётся выбором типа и существующего направления.
- В модели хранится `direction_id`, но отсутствует собственное отображаемое имя.
- API всегда возвращает актуальные `directionId` и `directionName`.
- Переименование направления сразу отражается во всех экзаменационных списках и карточках.
- Несколько экзаменов одного направления различаются типом и датой/периодом.

## Доменные признаки

- ID экзамена;
- тип `outside_lms | classic`;
- FK на направление;
- дата создания и изменения;
- type-specific поля даты/периода;
- вычисляемое имя направления.

## Ограничения

- Нельзя создать экзамен с отсутствующим направлением.
- Удаление используемого направления должно учитывать существующую политику справочника и не оставлять экзамен без имени.
- Имя направления нельзя копировать в новый mutable-атрибут экзамена.

## Зависимости

Нет. Это корневая задача.

## Критерии приёмки

- Создаются оба типа экзамена.
- Смена имени направления меняет имя экзамена без обновления записи экзамена.
- Списки можно фильтровать по типу, направлению и периоду.
- Ролевой доступ к базовой карточке соответствует бизнес-ТЗ.
