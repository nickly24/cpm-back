# FEX-12. Рабочее место администратора

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-12-admin-workspace.md).

## Цель

Собрать desktop-first интерфейс полного управления обоими типами экзамена.

## Функциональный результат

- Раздел экзаменов различает `Экзамен вне LMS` и `Классический экзамен`.
- Меню создания предлагает оба типа и выбор направления.
- Список поддерживает поиск, фильтры, дату/период и computed readiness.
- Карточка outside LMS содержит ручной CRUD результатов и переход к импорту.
- Workspace classic содержит основное, части/вопросы, scoring, комиссии, лист, текущие сдачи и результаты.
- Ошибки readiness ведут в конкретный раздел.
- Админ видит персональные голоса, раунды, замены, пересдачи и апелляции.
- Доступны просмотр листа и destructive delete-preview; новых экспортов нет.

## UX-ограничения

- Основное устройство — desktop.
- Длинные списки используют серверную пагинацию, поиск и фильтры.
- Редактирование не блокируется ручным статусом.
- При наличии активных сдач интерфейс предупреждает об организационном запрете менять конфигурацию, но не вводит новый статус.

## Зависимости

Функциональные контракты FEX-02–FEX-11.

## Критерии приёмки

- Все административные сценарии выполняются без обращения к БД вручную.
- Preview импортов редактируемый и не допускает скрытой перезаписи.
- Активные и завершённые сдачи диагностируются из одного workspace.
- Каскадное удаление невозможно без просмотра последствий.
