# FEX-07. Валидатор готовности классического экзамена

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-07-readiness.md).

## Цель

Заменить отсутствующий статус черновика вычисляемой, объяснимой проверкой готовности.

## Функциональный результат

- Админ и экзаменатор получают одинаковый структурированный перечень ошибок.
- Ошибки сгруппированы по разделам и ведут к месту исправления.
- Наличие ошибок не скрывает экзамен, но блокирует подготовку/старт затронутого назначения; лимит одного студента не блокирует остальных.
- Проверка пересчитывается после изменения конфигурации, банка, шкалы, назначения или привилегии.

## Проверяемые условия

- направление и период;
- хотя бы одна корректная часть;
- вес, квота и непустой банк каждой части;
- достаточность вопросов для конкретного студента: квота плюс его лимит; запас источника extra для продолжения без повтора подряд;
- корректность шкалы 0–5;
- полнота настроек спорного результата;
- допустимый источник дополнительного вопроса;
- комиссия конкретного студента из 1–6 действующих аккаунтов;
- доступность первой сдачи или назначенной пересдачи;
- попадание времени старта в интервал.

## Зависимости

FEX-04, FEX-05, FEX-06.

## Критерии приёмки

- Каждая ошибка имеет стабильный машинный код и понятный русский текст.
- Исправление последней ошибки делает старт доступным без ручного статуса.
- Backend повторяет проверку на каждой команде готовности/старта.
- Невалидный клиент не может обойти readiness прямым API-запросом.
