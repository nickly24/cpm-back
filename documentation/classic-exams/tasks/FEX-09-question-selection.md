# FEX-09. Случайная выдача и замена вопросов

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-09-question-selection.md).

## Цель

Реализовать серверную случайную выдачу вопросов по квотам частей и управляемую замену по привилегии.

## Функциональный результат

- Первый вопрос выбирается при старте; следующие regular — по кнопке; extra — автоматически по результату консенсуса.
- Оставшиеся слоты всех частей перемешиваются случайно с сохранением квот.
- Внутри выбранной части берётся случайный ещё не использованный вопрос.
- Основные вопросы не повторяются.
- Любой член комиссии может заменить текущий вопрос до первого голоса.
- Замена берётся из той же части и расходует единицу привилегии.
- Заменённый вопрос снапшотится, исключается из балла и навсегда запрещается в попытке.

## Второй круг

Используется для дополнительных спорных вопросов после исчерпания допустимого банка:

- новый случайный порядок;
- запрет немедленного повтора;
- разрешён повтор ранее показанных, но не заменённых вопросов;
- заменённые вопросы запрещены во всех циклах.

## Ограничения

- Дополнительный вопрос не уменьшает основную квоту.
- Несколько замен подряд разрешены в пределах лимита.
- Vote привязан к текущему показу/раунду, replace/next — к версии и показу; race не заменяет уже оценённый вопрос и не создаёт двойной следующий.

## Зависимости

FEX-04, FEX-08, привилегии FEX-06.

## Критерии приёмки

- Все квоты выполняются точно.
- Выдача и замены полностью воспроизводимы из протокола.
- После первого голоса замена возвращает бизнес-ошибку.
- Второй круг никогда не возвращает заменённый или только что показанный вопрос.
