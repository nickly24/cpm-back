# FEX-10. Голосование, консенсус и переголосование

**Статус:** декомпозирована для разработки — [техническая постановка](../development/FEX-10-voting.md).

## Цель

Обеспечить независимое голосование полного состава комиссии с неизменяемой историей конфликтов.

## Функциональный результат

- Каждый член выбирает только `0`, `0.5` или `1`.
- Голос отправляется один раз и не редактируется.
- До завершения раунда виден только собственный голос.
- После голосов полного состава сервер раскрывает раунд комиссии и админу.
- Совпадение фиксирует консенсус и блокирует вопрос.
- Расхождение автоматически открывает новый раунд без лимита.
- Все прошлые раунды сохраняются с экзаменатором, значением и временем.
- После обычного консенсуса любой член переходит дальше; последний необходимый консенсус автоматически публикует итог/extra.

## Видимость

- Комиссия и админ видят персональные голоса и все раунды.
- Студент видит только согласованный результат вопроса.
- Комментариев к голосам нет.

## Ограничения

- Голосовать может только участник снимка комиссии.
- Администратор и супервайзер не голосуют.
- Голос нельзя заменить апелляцией; апелляция работает только с финальной оценкой.

## Зависимости

FEX-08, FEX-09.

## Критерии приёмки

- Экзаменатору чужие голоса не раскрываются до полного раунда; админ видит весь протокол.
- Повторная отправка не меняет голос.
- Любое число конфликтных раундов сохраняется и читается страницами; шесть одновременных голосов одного раунда принимаются независимо.
- Консенсус невозможно изменить через публичный API.
